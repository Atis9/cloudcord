# 音声処理

Botが投稿を整形してWorkerへ送り、Workerが言語を選択してMeloTTSで音声を生成する。BotのFFmpegがWAV / MP3をOpusに変換してDiscordへ送る。音声生成に必要なモデルはすべてCloudflare Workers AI内で実行する。

## 言語

- ひらがな・カタカナを含む投稿: 日本語（MeloTTS `jp`）。
- 文字がLatin文字だけの投稿: 英語（`en`）。
- 漢字を含み、かなを含まない投稿: 判定専用モデル `@cf/cloudflare/clef` が日本語・中国語を選択する。
- 中国語と判定した投稿: 本文を変更せず `zh` へ渡す。中国語と英語の混在にも対応する。
- 数字・絵文字のみ、判定失敗、confidence 0.8未満: 日本語。

日中の短い共通表現は曖昧なので、日本語を優先する。confidenceの閾値は振り分け基準であり、正解率の保証ではない。言語判定は最大3秒、検証済みの高confidence判定をWorker isolate内で最大256件キャッシュする。

## 日本語の英単語

`@cf/qwen/qwen3-30b-a3b-fp8` が未キャッシュの英単語を最大32語まとめてカナ化する。入力は単語一覧のみ。最大256出力トークン、待ち時間1.5秒、再試行なし。結果の個数と文字種を検証し、最大512語をisolate内でキャッシュする。失敗・タイムアウト・対象数超過の場合は英字を1文字ずつ読む。

`KANA_MODE=llm` でカナ変換を有効にする。それ以外の設定では英字読みを使う。本文とカナ化後のテキストはいずれも先頭200文字まで。1投稿1回の音声生成を行い、言語判定・カナ化・音声応答の開始には合計25秒の上限を設ける。提出済みのAI binding推論自体はキャンセルできない。

## 設定とログ

内部APIは `language=ja` を既定言語として受け付け、Workerが実際の読み上げ言語を選ぶ。`X-Speech-Language` は `ja` / `en` / `zh`、`X-Kana-Source` はカナ化した場合に `llm` / `cache` / `fallback` を返す。ログには本文・読み・認証情報を含めない。

キャッシュはisolate単位で、再起動や別isolateには共有されない。日中判定では対象の投稿本文をモデルへ送り、カナ化では英単語一覧だけを送る。

## 費用

[Workers AI料金](https://developers.cloudflare.com/workers-ai/platform/pricing/)の無料枠をTTS・判定・カナ化で共有する。無料枠超過時の有料利用にはWorkers Paidが必要。

例として、1日100回・30日、1ドル150円と仮定した無料枠適用前の推論料:

| 処理 | 1回の入力 / 出力トークンの仮定 | 月額概算 |
| --- | --- | ---: |
| 日中判定（Clef） | 200 / 0 | 約22円 |
| カナ化（Qwen3） | 200 / 100 | 約20円 |

これは上限保証ではない。本文・質問・テンプレート・キャッシュ利用で実際のトークン数が変わる。TTS・Worker実行料・有料プラン基本料・税は別。最新の料金と利用量はCloudflareのDashboardで確認する。
